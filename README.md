
# ✈️ NaviTrip AI — Multi-Agent Travel Decision & Planning System

NaviTrip AI is an AI-powered travel decision and planning system that transforms a natural-language travel request into a practical, structured travel plan.

The system uses specialized AI agents coordinated through **LangGraph**, with real-world travel information retrieved through external APIs, web search, and **Model Context Protocol (MCP)** tools.

The current workflow combines **input guardrails, supervisor-based agent selection, dynamic routing, flight research, hotel research, weather information, budget analysis, itinerary generation, Human-in-the-Loop review, PostgreSQL checkpointing, and final response synthesis**.

> 🚧 **Project Status:** Active development. The current version implements the core multi-agent workflow with Supervisor routing, MCP integrations, Guardrails, Human-in-the-Loop approval, and PostgreSQL-based workflow persistence.

---

## 🎯 Project Overview

Travel planning often requires switching between multiple platforms to compare flights, research hotels, check weather, estimate costs, and create an itinerary.

NaviTrip AI brings these tasks together into one intelligent multi-agent system.

A user can provide a request such as:

> "Plan a 7-day Japan trip from Mumbai under ₹2.5 lakh including flights, hotels, sightseeing, and weather."

The system processes the request through a dynamic workflow rather than relying on a single LLM response.

## ✨ Features

* 🛡️ **Input Guardrails**

  * Validates travel-related requests before workflow execution.
  * Blocks irrelevant or invalid requests.

* 🧠 **Supervisor Agent**

  * Understands the user's travel requirements.
  * Extracts trip constraints.
  * Dynamically selects specialist agents.
  * Provides reasoning for agent selection.

* 🔀 **Dynamic Agent Routing**

  * Uses LangGraph conditional edges.
  * Routes execution based on the Supervisor's decision.
  * Supports revision routing after Human-in-the-Loop feedback.

* ✈️ **Flight Agent**

  * Uses AviationStack MCP.
  * Retrieves airport and airline information.
  * Generates flight-related travel guidance.

* 🏨 **Hotel Agent**

  * Uses Tavily MCP.
  * Performs web-based hotel and accommodation research.

* 🌤️ **Weather Agent**

  * Uses a custom Weather MCP server.
  * Retrieves current weather.
  * Retrieves weather forecasts.

* 💰 **Budget Agent**

  * Estimates trip costs.
  * Identifies budget risks.
  * Provides money-saving suggestions.
  * Evaluates overall budget feasibility.

* 🗺️ **Itinerary Agent**

  * Combines information from specialist agents.
  * Creates a practical and budget-aware itinerary.
  * Produces a draft for human review.

* 👤 **Human-in-the-Loop**

  * Pauses the workflow for user review.
  * Allows approval or revision feedback.
  * Routes revision feedback back through the Supervisor.

* ✨ **Final Response Agent**

  * Generates the final polished travel plan after approval.

## 🔄 Human-in-the-Loop Workflow

The itinerary generated by the system is treated as a draft.

```text
Specialist Agents
       │
       ▼
Itinerary Agent
       │
       ▼
Draft Itinerary
       │
       ▼
Human Review
       │
 ┌─────┴─────┐
 │           │
 ▼           ▼
Approve    Request Changes
 │           │
 ▼           ▼
Final      Supervisor
Plan          │
              ▼
        Relevant Agents
              │
              ▼
        Revised Itinerary
              │
              ▼
             HITL
```

Example revision feedback:

> "Reduce hotel costs and add more free sightseeing activities."

After approval, the intermediate draft/research sections are hidden and the final travel plan is displayed.

## 🔌 MCP Architecture

NaviTrip AI uses **Model Context Protocol (MCP)** to connect specialist agents with external tools.

### AviationStack MCP

Used by the Flight Agent for:

* Airport information
* Airline information
* Flight-related information

### Tavily MCP

Used by the Hotel Agent for:

* Web search
* Hotel research
* Accommodation information

### Custom Weather MCP

The project includes a custom Weather MCP server using OpenWeather.

Available tools:

```text
get_current_weather(city)
get_forecast(city)
```

The Weather MCP provides:

* Temperature
* Feels-like temperature
* Humidity
* Current conditions
* Forecast information

## 💾 PostgreSQL & LangGraph Checkpointing

NaviTrip uses PostgreSQL for LangGraph checkpoint persistence.

Each workflow is associated with a `thread_id`.

```text
User Request
     │
     ▼
LangGraph State
     │
     ▼
PostgreSQL Checkpoint
     │
     ▼
Human Review
     │
     ▼
Resume using thread_id
```

This allows a paused Human-in-the-Loop workflow to continue without losing its existing state.

## ⚙️ Installation

Make sure Python 3.10+ is installed.

Clone the repository:

```bash
git clone https://github.com/dataenthusiast26/NaviTrip-Multi-Agent-Travel-Planner-Using-MCP-Supervisor-Guardrails-HITL.git
```

Move into the project:

```bash
cd NaviTrip-Multi-Agent-Travel-Planner-Using-MCP-Supervisor-Guardrails-HITL
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Configure the required environment variables in `.env`.
